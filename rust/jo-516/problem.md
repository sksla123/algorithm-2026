# Jungol 516
## 문제
실수 2개와 한 개의 문자를 입력 받아 출력하되 실수는 반올림하여 소수 둘째자리까지 출력하는 프로그램을작성하시오.

## 조건
- 실행시간: 1s
- 최대 메모리: 32MB

## 힌트
- C, C++, Java 의 경우 실수는 "double"로 선언하세요.

## 예제 입출력
### #1 입력
```
12.2536 
526.129535 
A
```
### #1 출력
```
12.25 
526.13 
A
```
### #2 입력
```
92.1
3.14
N
```

### #2 출력
```
92.10
3.14
N
```
